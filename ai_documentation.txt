Prompt: what is ligotools egg info
Response (GPT): Excellent question — and it’s a common one when working with Python packaging.
🥚 What ligotools.egg-info Is
When you run
pip install .
or
pip install -e .
Python’s packaging tool setuptools builds some metadata about your package.
That metadata lives in a folder named:
ligotools.egg-info/
It contains files like:
PKG-INF
SOURCES.txt
top_level.txt
dependency_links.txt
requires.txt
These store things such as:
your package name, version, and author info (from pyproject.toml)
what files were included in the build
dependencies and entry points
Basically, it’s setuptools’ “manifest + metadata cache” for your package.
📦 Why It Appears
Because you built/installed your package in editable mode:
pip install -e .
That creates ligotools.egg-info/ inside your project root so that pip and Python know how to import your local version dynamically while you edit files.
🚫 Should You Commit It?
No — never commit .egg-info/ directories.
They are auto-generated and will differ across systems.
You should add it to your .gitignore file if it isn’t already:
# Packaging artifacts
*.egg-info/
dist/
build/
You already have this line in your .gitignore, so you’re good ✅
🧹 If You Ever Need to Delete It
You can safely remove it anytime:
rm -rf ligotools.egg-info
It will be recreated automatically next time you install your package.
Summary:
🥚 .egg-info = metadata folder auto-generated by setuptools
💡 It tells Python where your package is and what’s inside
🚫 Don’t commit it
🧹 Safe to delete; recreated on install

Prompt: Can you show me examples of how to write tests
Response (GPT): 5️⃣ General recipe for writing tests
When you write a test, think:
Arrange – set up inputs
Act – call your function
Assert – check the result or behavior
Example pattern:
def test_some_behavior():
    # Arrange
    x = ...
    y = ...

    # Act
    result = my_function(x, y)

    # Assert
    assert result == expected_value
And if it should error:
def test_error_case():
    with pytest.raises(SomeException):
        my_function(bad_input)
